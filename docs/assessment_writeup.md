# Assessment write-up

The application uses FastAPI, a Next.js/TypeScript interface, local MiniLM embeddings, ChromaDB, and an optional Gemini passage-selection stage. The seven URLs were verified against the supplied PDF's embedded hyperlinks. The crawler respects robots.txt, including the site's ten-second delay, and preserves headings, price qualifiers, and table rows. A versioned snapshot makes startup independent of a live crawl and supports rebuilding Chroma after an ephemeral host restart.

The main trade-off is conservative extraction instead of unrestricted prose generation. Prices are rendered from exact structured rows. Other factual answers contain source passages that must exactly match retrieved evidence and preserve complete lines. The model cannot create citation URLs. This protects numbers and qualifications but produces longer answers and cannot guarantee semantic relevance for every phrasing. Query analysis is deliberately constrained so visitor health narratives and contact details never reach Gemini's free tier.

Thirty evaluation cases cover the required eight categories plus package confusion, wrong destinations, privacy, prompt injection, multilingual framing, and missing information. Additional automated tests exercise source restrictions, failed refreshes, citation and numeric rejection, API authorization, and Gemini failure handling. Browser tests exercise the real frontend and backend. Results are actual local source-reading outputs, not fabricated Gemini outputs. A Gemini key was not available, so live model authentication, quota, and answer quality remain unverified. The source-reading demo is explicitly labeled.

Known limitations include conservative comparison refusals, incomplete multilingual translation (source evidence remains in English), a finite topic vocabulary, and process-local session/rate-limit state. Website promotional claims are attributed to their sources, not presented as established clinical evidence. The temporary public tunnel depends on the host remaining awake and online; seven-day cloud availability is not verified.

With another week, I would activate and evaluate the configured Gemini free-tier project, broaden clinician-reviewed intent and entity tests, improve passage-level relevance evaluation, add verified translations with a separate evidence-preservation check, review additional source-layout fixtures, and deploy to a connected free host with restart and seven-day availability monitoring. None of those future steps requires expanding the seven-source knowledge scope.
