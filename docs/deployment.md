# Deployment and public demo

The current public smoke result, URL, and timestamp are recorded in `docs/public-smoke.json`. This is a Cloudflare Quick Tunnel to the local FastAPI process. It is a useful live review link only while this computer is awake, online, and running both services. A Quick Tunnel URL can change after restart and has no uptime guarantee. The app labels its mode as source reading because no Gemini key is configured.

To start it on this Linux user session after local setup and a successful `npm run build`, run `bash scripts/start_demo.sh`. This creates two user services, `placidway-ai-demo` and `placidway-ai-tunnel`, with restart policies. User lingering is enabled on this host so the service manager can remain active after logout. `data/logs/public-tunnel.log` contains the assigned URL. Check `systemctl --user status placidway-ai-demo placidway-ai-tunnel`. Stop with `systemctl --user stop placidway-ai-tunnel placidway-ai-demo`. These services do not keep a sleeping machine awake or provide cloud availability.

`Dockerfile` packages the static frontend, Python API, portable source snapshot, and pinned ONNX MiniLM assets. It runs one Uvicorn worker with no proxy-header trust. `render.yaml` specifies a free web service, but no Render account was connected in this workspace and no Render deployment has been made. A deployment should remain private during credential setup, be checked for memory fit and cold-start behavior, and be tested at its actual URL. Free web services can sleep or be suspended and ephemeral disk content is reconstructed from the snapshot at startup. The working source-reading demo does not prove a seven-day public deployment.

For a Gemini deployment, the operator must confirm the chosen project's free-tier entitlement and eligible audience/region, disable paid billing, set the key as a secret and `GEMINI_FREE_TIER_CONFIRMED=true`, run `scripts/verify_gemini.py`, and execute the 30-case Gemini evaluation against the live service. The model name alone does not establish free-tier eligibility or that live generation works. Google Gemini API terms and regional restrictions must be checked for the deployment and users, especially because this application concerns health information. The service deliberately does not turn on Gemini when those checks are missing.

Useful primary references: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/), [Render free services](https://render.com/docs/free), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [Gemini API terms](https://ai.google.dev/gemini-api/terms).
