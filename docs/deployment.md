# Deployment and public demo

The active public deployment is [placidway-ai.vercel.app](https://placidway-ai.vercel.app), with Gemini enabled. The previous public smoke result, URL, and timestamp in `docs/public-smoke.json` describe a historical Cloudflare Quick Tunnel to the local FastAPI process in source-reading mode. That tunnel depended on this computer remaining awake and online. Its URL could change after restart and it had no uptime guarantee.

To start it on this Linux user session after local setup and a successful `npm run build`, run `bash scripts/start_demo.sh`. This creates two user services, `placidway-ai-demo` and `placidway-ai-tunnel`, with restart policies. User lingering is enabled on this host so the service manager can remain active after logout. `data/logs/public-tunnel.log` contains the assigned URL. Check `systemctl --user status placidway-ai-demo placidway-ai-tunnel`. Stop with `systemctl --user stop placidway-ai-tunnel placidway-ai-demo`. These services do not keep a sleeping machine awake or provide cloud availability.

`Dockerfile.vercel` packages the static frontend, Python API, portable source snapshot, and pinned ONNX MiniLM assets. It runs one Uvicorn worker with no proxy-header trust. `render.yaml` remains an unused alternative; no Render deployment was made. The Vercel app was tested at its actual URL, but a point-in-time check does not prove seven days of availability.

For this Gemini deployment, the user reported the Google AI Studio project as Free + Active, the key was stored as a sensitive Vercel variable, and the live service reported Gemini configured. The required eight cases passed against production; the 30-case Gemini evaluation was run locally. The model name alone does not establish ongoing free-tier eligibility. Keep paid billing disabled and check Google Gemini API terms, regional restrictions, and current usage, especially because this application concerns health information. The service deliberately does not turn on Gemini when key and free-tier confirmation are missing.

Useful primary references: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/), [Render free services](https://render.com/docs/free), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [Gemini API terms](https://ai.google.dev/gemini-api/terms).

For the combined frontend and backend on Vercel Hobby, follow [Vercel deployment](vercel-deployment.md). That target packages the same source snapshot and model but restores its writable index into instance-local temporary storage.
